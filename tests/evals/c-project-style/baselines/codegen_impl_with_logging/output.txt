Here is the `_udp_bind` static helper following xylem conventions:

```c
static int _udp_bind(int fd, uint16_t port) {
    struct sockaddr_in addr = {0};
    addr.sin_family      = AF_INET;
    addr.sin_addr.s_addr = htonl(INADDR_ANY);
    addr.sin_port        = htons(port);

    if (bind(fd, (struct sockaddr*)&addr, sizeof(addr)) != 0) {
        int err = platform_socket_errno();
        xylem_loge("<udp> bind failed port=%d err=%d", port, err);
        return -1;
    }
    return 0;
}
```

Conventions applied: the function is a static helper so it uses the `_<module>_<action>` name `_udp_bind`. The error log goes through `xylem_loge` (error level only -- no self-initiated `logd`/`logi`/`logw`), starts with the `<udp>` module tag, and uses `key=value` pairs (`port=%d err=%d`) rather than a sentence. The `if` body uses braces, the return convention is `0`/`-1`, and there are no `//` comments and no non-ASCII characters.
